OAS 3.1

/v3/api-docs

REST API for Wandora stays: authentication, user profiles, friendships, hotels and rooms, hosts and applications, bookings, payments, booking drives and collaborative travel planning. Authenticated routes expect the HttpOnly ACCESS_TOKEN session cookie issued by POST /api/auth/login or POST /api/auth/register; use the Authorize button to supply its value. Every error response uses the project's ApiError envelope (success, message, error, dateTime, info).

Servers

Host Profile

Host profile creation and maintenance, plus host phone/email OTP verification. All routes require an authenticated session.

Rooms

Room creation, lookup and deactivation for a hotel. All routes require an authenticated session.

Booking Drive

Trip photo storage attached to a booking. All routes require an authenticated session.

User Discovery

Browse other users of the platform. All routes require an authenticated session.

Friendships

Friend requests and friendship lookups between existing users. All routes require an authenticated session.

Bookings

Booking creation, guests, payment initiation and cancellation. All routes require an authenticated session.

Authentication

Account registration, sign-in, session refresh, OTP verification and logout. Sessions are issued as HttpOnly cookies (ACCESS_TOKEN, REFRESH_TOKEN), not as bearer tokens.

Host Applications

Host onboarding applications and their identity documents. All routes require an authenticated session.

My Profile

Read and update the authenticated user's own profile. All routes require an authenticated session.

Hotel Search

Public hotel and room discovery. The search route and its public photo/info helpers are listed as permitAll routes in the security configuration.

Hotels

Hotel creation, maintenance, photos, hotel applications and hotel bookings for hosts. All routes require an authenticated session.

Admin

Administrator-only operations. Every route requires the persisted ADMIN role (exposed to Spring Security as ROLE_ADMIN); non-admin sessions receive 403.

Payments

Razorpay payment verification and payment webhooks.
